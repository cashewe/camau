# Issue tracker: GitHub

Issues and specifications live in GitHub Issues for `cashewe/camau`. Use the `gh` CLI for operations and infer the repository from the current Git remote.

## Conventions

- Create issues with `gh issue create`.
- Read issues and comments with `gh issue view`.
- List issues with `gh issue list`.
- Update labels with `gh issue edit`.
- Close issues with `gh issue close`.
- When a skill says “publish to the issue tracker,” create a GitHub issue.
- Pull requests are not treated as a triage request surface.
