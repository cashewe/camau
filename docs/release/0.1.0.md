# Camau 0.1.0 release evidence

## Compatibility and packaging

- Maturin 1.15.0 built `camau-0.1.0-cp311-abi3-win_amd64.whl` from the locked dependency graph in release mode.
- The built wheel was force-installed into CPython 3.13.14 and passed all 52 public Python tests.
- Release CI tests CPython 3.11, 3.12, 3.13, and 3.14 on Linux x86-64, Linux ARM64, and Windows x86-64. It builds CPython 3.11 stable-ABI wheels for the same platforms.
- Rust property and stress tests passed, including generated cycles, weighted routes, generated flow topologies, and a 10,000-node graph.

## Security

- `cargo-audit 0.22.2` loaded 1,233 RustSec advisories and found no vulnerabilities across the 66 dependencies in `Cargo.lock`.
- `pip-audit 2.10.1 --local` found no known vulnerabilities. The local, unpublished Camau wheel was correctly skipped because it does not yet exist on PyPI.
- No advisory exception or maintainer approval is required.

## Performance

The release benchmark used a 10,251-byte JSON object, 200 warm-up runs, and 2,000 measured samples on Windows 11, CPython 3.13.14, and an Intel64 Family 6 Model 142 CPU.

| Workload | p50 | p95 | Objective |
|---|---:|---:|---:|
| Ten-node linear workflow | 0.2254 ms | 0.4310 ms | p95 ≤ 1 ms |
| Ten-branch fan-out/converge | 0.1230 ms | 0.2597 ms | p95 ≤ 2 ms |

The 100,000-run linear soak changed RSS from 40,202,240 bytes to 40,079,360 bytes, a decrease of 122,880 bytes. No sustained memory growth was observed. Raw results are in [the benchmark record](../../tests/benchmarks/results/2026-08-31-windows-x64.json).

No performance exception or maintainer approval is required.
