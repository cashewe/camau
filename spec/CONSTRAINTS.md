# constraints

1. the solution must be as performant as possible, to avoid slowing down prediction.
2. the solution must use a human readable / editable configuration format, ideally JSON
3. the solution must make the editable surface for routing rules obvious
4. the solution must be designed to potentially expand to new rule types as new requirements become obvious
5. the solution must support fan-out behaviour
6. the solution must support converging behaviour
7. the solution must be built with machine learning teams in mind, using tooling and vocabulary that will be familiar to them
8. the solution must be fully modular, with no unexpected incompatibilities
